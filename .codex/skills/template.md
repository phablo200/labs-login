# API Reviewer Skill

## Purpose
Review API implementations and suggest improvements.

## When to Use
Use this skill when analyzing REST APIs, OpenAPI specs, or backend endpoints.

## Instructions

1. Analyze endpoint naming consistency
2. Validate HTTP status codes
3. Check authentication patterns
4. Review pagination/filtering
5. Suggest improvements

## Output Format

- Summary
- Problems Found
- Suggestions
- Example Fixes
